# Skills

Procedures for the Quartz site. `.kiro/steering/` holds the rules; this holds the recurring
jobs.

| Skill | Use it when |
|---|---|
| **`verify-the-site`** | Any change that could affect rendering — a plugin, a transformer, a config option, or a dependency bump. Also the first thing to reach for when something "doesn't work" locally. |

`SKILL.md` is navigation, not the answer: if the detail you need is in a `references/` file,
read it before acting.

For the vault's own procedures (bulk edits, conventions), see `.kiro/skills/` in the vault
repo.
